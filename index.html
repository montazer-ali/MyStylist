Gemini API key
This app runs standalone in your browser, so it needs your own Google Gemini API key to recognize photos and suggest outfits. Get a free key at aistudio.google.com/apikey. The key is stored only in this browser (localStorage) and sent directly from your browser to Google — it never passes through any other server. Don't share this file with the key already saved in it, and don't use this on a shared/public computer.
Your photo
Add a clear photo of yourself (face and body visible, plain background works best) and outfit suggestions can include a generated picture of you wearing the look. Stored only in this browser, same as everything else.
